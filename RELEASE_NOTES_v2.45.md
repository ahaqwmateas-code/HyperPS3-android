## 🔧 Technical Features

### API Endpoints (Auto-Update)
```
GET  /api/trpc/autoUpdate.checkForUpdates
GET  /api/trpc/autoUpdate.getLatestAppVersion
GET  /api/trpc/autoUpdate.getPendingCrashFixes
GET  /api/trpc/autoUpdate.getPendingMods
POST /api/trpc/autoUpdate.markUpdateInstalled
POST /api/trpc/autoUpdate.applyCrashFix
POST /api/trpc/autoUpdate.enableMod
GET  /api/trpc/autoUpdate.getUpdateStatistics
```

### Crash Fix Endpoints
```
GET  /api/trpc/crashFixes.getCrashFixForGame
GET  /api/trpc/crashFixes.getSpecialMods
GET  /api/trpc/crashFixes.getRecommendedMods
GET  /api/trpc/crashFixes.getOptimalSettings
```

### Configuration Endpoints
```
GET  /api/trpc/appConfig.getConfig
GET  /api/trpc/appConfig.getGameSettings
GET  /api/trpc/appConfig.getPerformanceProfile
GET  /api/trpc/appConfig.getSpecialFeatures
```
